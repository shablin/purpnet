# purpnet

It's my small educational project for learning
network programming in Crystal Language:
- TCP/UDP layers
- Client-Server architecture

*Idea:* A server that can accept connections from
LAN and provide message exchange and file transfer

## Installation

1. Clone this repo
2. Make sure you have installed Crystal on
you PC
3. Build executable file from `src/purpnet.cr`
using `crystal build`

## Usage

1. Call executable file after it's been built
2. Check out what the commands are available
3. Have fun
